# Submission video checklist

- [ ] Record a 3–5 minute end-to-end demonstration.
- [ ] Use synthetic data and a prepared account; hide credentials, private tokens, browser password prompts and personal records.
- [ ] Show the actual selected speech language and explicit consent.
- [ ] If live ASR is unavailable, identify the manual or fixture path accurately.
- [ ] Show transcript/suggestion separately from the confirmed ledger record.
- [ ] Show explicit user review and save confirmation.
- [ ] Demonstrate a useful financial summary and distinguish cash flow from profit.
- [ ] State live N-ATLAS request results and real-user interaction counts accurately.
- [ ] Check audio clarity, legible mobile layout and captions/subtitles.
- [ ] Review the exported video for accidental secrets, emails, customer details and share links.
- [ ] Confirm the application portal's accepted file/URL format before upload.

Recording and submission are external actions; no video or application is created by this checklist.
